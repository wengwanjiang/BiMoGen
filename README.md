# BiMoGen

**Bidirectional Motion-Text Generation via Unified Masked Discrete Diffusion**

Accepted at **NeurIPS 2026**.

Wanjiang Weng, Yongliang Wu, Xiaofeng Tan, Xingyu Zhu, Wenbo Zhu, and Hongsong Wang

**Equal contribution:** Wanjiang Weng and Yongliang Wu.

**Corresponding author:** Hongsong Wang.

## Overview

This is the official repository for BiMoGen, a unified masked discrete diffusion framework for bidirectional motion-text generation. BiMoGen supports both text-to-motion generation and motion-to-text captioning through two-stage training and generation-aware self-correction.

## Code Release

The source code is not yet publicly available. We are committed to open-sourcing BiMoGen and will release the implementation in this repository after completing code cleanup and documentation.

Release updates and usage instructions will be provided here. Thank you for your interest and patience.
