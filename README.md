> **TL;DR:** BiMoGen unifies text-to-motion generation and motion-to-text captioning through masked discrete diffusion, combining two-stage training with generation-aware self-correction.

This is the official repository for **BiMoGen**, accepted at **NeurIPS 2026**. The implementation will be released here.
